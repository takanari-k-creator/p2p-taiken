# P2P体験（ペア通信）

高校「情報Ⅰ」で、P2P（ピア・ツー・ピア）通信の仕組みを体験するWeb教材です。インストールは不要で、ブラウザで開くだけで使えます。

**使うページ：** https://takanari-k-creator.github.io/p2p-taiken/

姉妹教材：[クライアントサーバ体験](https://takanari-k-creator.github.io/client-server-taiken/)（2つを比べて使うと効果的です）

## できること
- 「はじめる」を押すと、自分の仮想IPアドレス（例：`192.168.23.45`）が表示されます
- ペアの相手のIPアドレスを入れて接続すると、サーバを通さずに**直接**メッセージをやりとりできます
- 通信の相手は1人だけです。ほかの人が接続しようとすると断ります
- 送信元IP・宛先IP・種類・データの中身・サイズを**通信データログ**で確認でき、CSVで保存できます

## 注意
- IPアドレスは教材の中だけで使う仮想のもので、端末の本物のIPアドレスではありません
- 端末どうしの通信には WebRTC（PeerJS）を使います。最初に相手を見つけるときだけ、PeerJS の公開仲介サーバを使います。つながった後のメッセージは、端末どうしで直接やりとりします
- メッセージはどこにも保存されません。ページを閉じると消えます
- 校内ネットワークの設定によっては接続できないことがあります。授業の前に、数台でテストしてください

## 動作環境
Chrome または Edge の最新版
